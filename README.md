# jobtrackr
A full-stack job application tracker: kanban pipeline (Saved > Applied > Interview > Offer/Rejected), notes, reminders and funnel analytics.

**Goal:** show production-style web dev: Next.js 14 App Router + TypeScript, auth (Auth.js: GitHub OAuth + email magic link), Prisma ORM on Postgres (SQLite locally), server actions, Zod validation, role-scoped data, tests and CI.

**Scope (v1):** sign in/out · CRUD applications + drag-and-drop kanban · per-user data isolation · CSV import/export · funnel and response-rate charts · demo mode with seeded data (no login) exported as a static site to GitHub Pages.

Status: scaffolding. Roadmap in issues.
